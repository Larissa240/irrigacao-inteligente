#Irrigação Inteligente

## Sobre o projeto

O projeto Irrigação Inteligente tem como
objetivo desenvolver um sistema automatizado
de monitoramento e controle da irrigação,
utilizando ESP32, sensores de umidade do solo
e comunicação MQTT.

## Objetivos

- Monitorar a umidade do solo.
- Automatizar o processo de irrigação.
- Reduzir o desperdício de água.
- Permitir acompanhamento por interface web.
- Utilizar comunicação MQTT entre dispositivos.

## Tecnologias utilizadas

- ESP32
- Arduino IDE
- HTML5
- CSS3
- JavaScript
- MQTT
- Eclipse Mosquitto

## Funcionamento previsto

1. O sensor mede a umidade do solo.
2. O ESP32 processa as leituras.
3. Os dados são enviados por MQTT.
4. O dashboard apresenta as informações.
5. A irrigação poderá ser acionada conforme
   as regras configuradas.

## Estrutura do repositório

- esp32/ — Código e configurações do ESP32.
- dashboard/ — Interface web de monitoramento.
- broker/ — Configuração de exemplo do Mosquitto.
- documentacao/ — Relatórios, diagramas e testes.
